## Selected work

### Devices and developer tools

- [**Qt-SmartID-Reader-Service**](https://github.com/hasanhuseyinyetkiner/Qt-SmartID-Reader-Service) — C++/Qt service for smart-card and serial barcode readers, with D-Bus integration and a remote validation interface.
- [**codextractor**](https://github.com/hasanhuseyinyetkiner/codextractor) — a Python command-line tool that turns selected repository files into structured Markdown for review and analysis.
- [**pop-lingo**](https://github.com/hasanhuseyinyetkiner/pop-lingo) — Linux desktop translation and dictionary workflows.

### Applied systems experiments

- [**Workforce Optimizer**](https://github.com/hasanhuseyinyetkiner/workforce-optimizer) — constraint-based shift scheduling with OR-Tools CP-SAT and a separate validator for the resulting roster.
- [**HR Policy Copilot**](https://github.com/hasanhuseyinyetkiner/hr-policy-copilot) — hybrid retrieval and extractive question answering over versioned policy documents, with citations and an evidence gate.

Explore a [recorded interactive tour](https://hasanhuseyinyetkiner.github.io/hasanhuseyinyetkiner/) of both projects. It uses synthetic data and switches between captured screens; their READMEs explain how to run the applications and inspect the evaluation.

Additional experiments: [Hiring Process Miner](https://github.com/hasanhuseyinyetkiner/hiring-process-miner) · [FairHire Audit](https://github.com/hasanhuseyinyetkiner/fairhire-audit) · [SkillGraph](https://github.com/hasanhuseyinyetkiner/skillgraph).
