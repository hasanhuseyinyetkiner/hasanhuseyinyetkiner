# Recorded HR engineering demos

A buildless static tour of screenshots and GIFs from the sibling Workforce Optimizer and HR Policy Copilot projects. All captures use synthetic data. The page does not run either application, a solver, or an AI model.

From `docs/`, run `python -m http.server 8000` and open `http://localhost:8000/`. No dependencies or build step are needed. GitHub Pages can serve this `docs/` folder as the publishing root; all site assets use relative paths.

The copied captures originate in [Workforce Optimizer](https://github.com/hasanhuseyinyetkiner/workforce-optimizer/tree/main/docs) and [HR Policy Copilot](https://github.com/hasanhuseyinyetkiner/hr-policy-copilot/tree/main/docs). See those repositories for implementation, evidence, licenses and instructions to run the actual applications. With JavaScript disabled, the initial images, GIF links and links to the remaining screenshots remain available.
